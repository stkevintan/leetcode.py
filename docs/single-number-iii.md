# 只出现一次的数字 III — 异或分组 O(n) / O(1)

---

## 一、问题

数组中有两个元素各出现**恰好一次**，其余元素都出现**恰好两次**。找出这两个只出现一次的数。

---

## 二、思考路径：退化 → 扩展

### 退化问题（LC 136）：只有一个单次数字

全数组异或即可。理由：

- $x \oplus x = 0$：成对的数全部抵消
- 异或满足交换律/结合律，顺序无所谓
- 剩下 $0 \oplus a = a$

### 扩展到两个单次数字 a、b

全异或后得到 `xor = a ^ b`（成对的全抵消）。

由于 $a \ne b$，$a \oplus b \ne 0$，所以 `xor` 里**至少有一个 1 位**——这个 1 说明 a 和 b 在该位不同。

### 核心技巧：用「不同的一位」把数组一分为二

取最低的 1 位：`low_bit = xor & -xor`。

按这一位把 `nums` 分成两组（该位为 1 / 该位为 0）：

1. **a 和 b 必然分到不同组**——它们在这一位不同
2. **成对的数必然落在同一组**——同一个数两次，这一位当然相同

于是每组都退化成了「只有一个单次数字」的问题，分别异或即可。

---

## 三、模拟

```
nums = [1, 2, 1, 3, 2, 5]

全异或: 1^2^1^3^2^5 = 3^5 = 6 = 110₂
low_bit = 6 & -6 = 2 = 010₂        (第 1 位是 3=011₂ 与 5=101₂ 第一个不同的位)

按第 1 位分组:
  第 1 位为 1: 2, 2, 3  → 异或得 3
  第 1 位为 0: 1, 1, 5  → 异或得 5

答案: [3, 5]
```

---

## 四、代码

```python
from functools import reduce

class Solution:
    def singleNumber(self, nums: list[int]) -> list[int]:
        xor = reduce(int.__xor__, nums)   # a ^ b
        low_bit = xor & -xor              # 最低的 1 位
        x1, x2 = 0, 0
        for x in nums:
            if x & low_bit:
                x1 ^= x
            else:
                x2 ^= x
        return [x1, x2]
```

---

## 五、为什么正确

设 `low_bit` 是 `a ^ b` 的某一位 1（比如最低位），记该位为 bit k：

- a 和 b 在第 k 位不同 → 一个在组 1，一个在组 2
- 对任意成对出现的 (x, x)，两次 x 的第 k 位相同 → 落在同一组
- 所以每组内部 = 「一个单次数字 + 若干成对数字」→ 组内异或即答案

---

## 六、lowbit 技巧：`xor & -xor`

负数是补码表示：

- `-xor` 与 `xor` **最低的 1 位相同**，更低的全 0，更高的全部取反
- 按位与之后，只剩最低的那个 1

```
 xor = 0110   (6)
-xor = 1010   (补码)
  &  = 0010   (2)  ← 最低位 1
```

对负数同样成立（Python 无限精度补码语义），所以 `x & low_bit` 直接判断该位即可，无需处理符号。

---

## 七、复杂度

- 时间：$O(n)$，两次遍历
- 空间：$O(1)$

---

## 八、一句话总结

**异或消掉成对的，再用「a 和 b 不同的一位」做分组，把两个单次数字拆成两个独立的小问题。**
