# 单调栈：从"怎么用"到"为什么"

---

## 一、单调栈的本质

单调栈维护一组元素，保持**单调递增**或**单调递减**。当新元素破坏单调性时，弹出栈顶——**弹出的那一刻，被弹出元素的"命运"被新元素决定了**。

---

## 二、两种计算时机

### 模式 A：弹出时算（被弹出者是主角）

被弹出元素的**范围到此为止**，新元素是它的边界。

```
      ██
    ████        ← 4 来了，3 被弹出
  ██████        → 3 的右边界 = 4 的位置
████████
  ↑    ↑
 left  i
```

**适用**：需要同时看到左右边界的题

| 题号 | 题目 | 弹出时算什么 |
|------|------|------------|
| 84 | 柱状图最大矩形 | 以弹出高度为最矮的矩形面积 |
| 42 | 接雨水 | 弹出者作为凹槽底部的积水量 |
| 85 | 最大矩形 | 84 的二维版 |

```python
# 核心模板
while stack and heights[stack[-1]] > h:
    j = stack.pop()
    left = stack[-1] if stack else -1     # 左边界(栈里下一个)
    ans = max(ans, heights[j] * (i - left - 1))  # 右边界 = i
```

### 模式 B：压入时算（被压入者是裁判）

新元素的到来，**解救了栈里等待的旧元素**。

```
stack → [等待者1, 等待者2, 等待者3]
push →   🔥答案来了！
         栈里所有更小的都得到答案
```

**适用**：只需要看一侧的题

| 题号 | 题目 | 压入时算什么 |
|------|------|------------|
| 739 | 每日温度 | 栈里元素的下一个更高温度距离 |
| 496 | 下一个更大元素 I | 栈里元素的下一个更大值 |
| 503 | 下一个更大元素 II | 同上，循环数组版 |

```python
# 核心模板
for i, t in enumerate(temperatures):
    while stack and t > temperatures[stack[-1]]:
        j = stack.pop()
        ans[j] = i - j    # 新元素的到来决定了旧元素的答案
    stack.append(i)
```

## 三、方向对称性：正向 vs 逆向

同一道题，倒过来遍历，计算时机可能**翻转**。

```
正向:  新元素 ①→②→③→④  栈里存"过去"
逆向:  新元素 ④→③→②→①  栈里存"未来"
```

### 739. 每日温度

| | 正向 | 逆向 |
|---|---|---|
| 遍历方向 | `0 → n-1` | `n-1 → 0` |
| 栈里存什么 | 还没找到答案的"待解救者" | 未来的"答案库" |
| 新元素角色 | 来解救栈里的人 | 来查询栈里的答案 |
| 计算时机 | **pop 时算** | **append 时算** |

```python
# 正向（模式 B，pop 时算）
for i, t in enumerate(temperatures):
    while stack and t > temperatures[stack[-1]]:
        j = stack.pop()
        ans[j] = i - j
    stack.append(i)

# 逆向（模式 B 翻转，append 时算）
for i in range(n - 1, -1, -1):
    while stack and temperatures[stack[-1]] <= temperatures[i]:
        stack.pop()
    if stack:
        ans[i] = stack[-1] - i    # 栈顶就是答案
    stack.append(i)
```

### 84. 柱状图最大矩形

这道题无论正向还是逆向，**都是 pop 时算**。因为矩形的面积需要同时知道左边界和右边界，缺一不可。

| | 正向 | 逆向 |
|---|---|---|
| pop 触发 | 矮柱子出现（右边界确定） | 矮柱子出现（左边界确定） |
| 已知边界 | 左边界(栈内) | 右边界(栈内) |
| 新来的是 | 右边界 | 左边界 |
| 收尾 | 需要（末尾哨兵 0） | 需要（开头哨兵 0） |

## 四、核心洞察：视野决定时机

为什么 739 倒过来可以 "append 时算"，84 倒过来却不行？

```
739. 每日温度          84. 柱状图最大矩形
视野: 柱子 →          视野: ← 柱子 →
单向，只需看右边       双向，需要左右边界
                           ↓
倒过来：右边在栈里      倒过来：右边在栈里，但左边还没出现
→ 看一眼栈顶就行        → 还是得等左边出现（pop 时算）
```

> **看一边**的题，倒过来可以把答案提前准备好 → append 时算  
> **看两边**的题，无论怎么倒，缺的那一侧没出现之前永远算不了 → pop 时算

## 五、哨兵技巧

在数组开头/末尾补一个极小值，让所有元素自然弹出，省去收尾循环。

```python
# 84 题正向：末尾补 0
heights.append(0)
for i, h in enumerate(heights):
    while stack and heights[stack[-1]] > h:
        j = stack.pop()
        left = stack[-1] if stack else -1
        ans = max(ans, heights[j] * (i - left - 1))
    stack.append(i)

# 84 题逆向：开头补 0
heights.insert(0, 0)
# 其余逻辑镜像...
```

## 六、接雨水 (42) 的特殊性

接雨水有两种单调栈写法，对应两种"理解世界"的方式：

### 写法 1：base 层累加法

```python
base = 0
while stack and height[stack[-1]] <= v:
    p = stack.pop()
    ans += (i - p - 1) * (height[p] - base)  # 只算比 base 多出的一层
    base = height[p]                           # 逐层向上
if stack:
    ans += (v - base) * (i - stack[-1] - 1)
```

### 写法 2：凹槽法（更直觉）

```python
while stack and height[stack[-1]] < h:
    bottom = stack.pop()          # 凹槽底
    if not stack: break
    left = stack[-1]              # 左墙
    w = i - left - 1
    hh = min(height[left], h) - height[bottom]  # 水深 = 矮墙 - 槽底
    ans += w * hh
```

## 八、选择题型速记

```
题目问"下一个更大/更暖"  → 模式 B（压入时算），递减栈
题目问"最大矩形/最多水"  → 模式 A（弹出时算），递增栈
题目问"字典序/去重复"    → 模式 A + 额外条件
```
