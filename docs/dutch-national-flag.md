# 荷兰国旗问题 (Dutch National Flag) — 三指针单次遍历

---

## 一、问题

将只含 `0, 1, 2` 的数组**原地**排成 `[0...0, 1...1, 2...2]`，O(n) 时间，O(1) 空间。

---

## 二、三指针不变量

维护三个指针，将数组分成四个区域：

```
[0, p0)      全 0
[p0, i)      全 1
[i, p2]      未知（待扫描）
(p2, n-1]    全 2
```

初始状态：

```
p0 = 0          ← 下一个 0 应该放的位置
i  = 0          ← 当前扫描位置
p2 = n - 1      ← 下一个 2 应该放的位置
```

每次只看 `nums[i]`：

| `nums[i]` | 操作 | i 移动？ |
|:---:|------|:---:|
| 0 | swap(i, p0)，p0++ | ✅ i++ |
| 1 | 不动 | ✅ i++ |
| 2 | swap(i, p2)，p2-- | ❌ i 不动 |

---

## 三、代码

```python
def sortColors(self, nums: List[int]) -> None:
    p0, p2 = 0, len(nums) - 1
    i = 0
    while i <= p2:
        if nums[i] == 0:
            nums[i], nums[p0] = nums[p0], nums[i]
            p0 += 1
            i += 1
        elif nums[i] == 2:
            nums[i], nums[p2] = nums[p2], nums[i]
            p2 -= 1
        else:
            i += 1
```

---

## 四、为什么 0 能 i++，2 不能？

### `nums[i] == 0` 时：交换后 i++ 是安全的

```
[0, 0, 1, 1, ?, ?, 2, 2]
       ↑  ↑     ↑     ↑
      p0  i    未知  p2

swap(i, p0):
  原本 nums[p0] 在 [p0, i) 区间 → 一定是 1
  换到 i 位置后，这个 1 已经在正确位置
  → i++ 继续看下一个 ✓
```

### `nums[i] == 2` 时：交换后 i 不能动

```
[0, 0, 1, 1, ?, ?, 2, 2]
             ↑  ↑     ↑
            未知 i     p2

swap(i, p2):
  原本 nums[p2] 在 [i, p2] 区间 → 未知！
  换到 i 位置后，可能是 0、1、2 任意一个
  → i 必须不动，下一轮重新判断
```

## 五、完整模拟

```
nums = [2, 0, 2, 1, 1, 0]
        p0=0, p2=5, i=0

i=0: [2,0,2,1,1,0]  2 → swap(0,5) → [0,0,2,1,1,2]  p2=4
i=0: [0,0,2,1,1,2]  0 → swap(0,0) → [0,0,2,1,1,2]  p0=1, i=1
i=1: [0,0,2,1,1,2]  0 → swap(1,1) → [0,0,2,1,1,2]  p0=2, i=2
i=2: [0,0,2,1,1,2]  2 → swap(2,4) → [0,0,1,1,2,2]  p2=3
i=2: [0,0,1,1,2,2]  1 → i=3
i=3: [0,0,1,1,2,2]  1 → i=4
i=4: i(4) > p2(3) → 结束
```

---

## 六、正确处理 `[2, 0, 1]` 这个典型坑

```
nums = [2, 0, 1]
        p0=0, p2=2, i=0

i=0: 2 → swap(0,2) → [1,0,2]  p2=1, i=0
i=0: 1 → i=1
i=1: 0 → swap(1,0) → [0,1,2]  p0=1, i=2
i=2: i(2) > p2(1) → 结束 ✓
```

---

## 七、不变量验证

每次操作后，检查不变量仍然成立：

```
swap(0 相关)后: [0, p0) 增加一个 0, [p0, i) 不变（换进来的 1 还在）
swap(2 相关)后: (p2, n-1] 增加一个 2, i 不变（待重新判断换进来的）
i++ 后:        [p0, i) 增加一个 1
```

---

## 八、与快排的关系

荷兰国旗问题是**快排 partition 的泛化**。标准快排 partition 分成两区（≤pivot 和 >pivot），这里是三区（<pivot, =pivot, >pivot）。三路快排对有大量重复元素的数组效率远高于标准快排：

```
标准快排:  [ < pivot | >= pivot ]     递归处理两边
三路快排:  [ < pivot | = pivot | > pivot ]  中间部分不用递归
```
