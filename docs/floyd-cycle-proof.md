# Floyd 判圈算法 — 环入口的数学证明

---

## 一、定义

```
        非环部分 (a)      环内部分 (b)
    ┌─────────────────┬──────────────┐
    │                 │              │
    0 → 1 → 2 → ... → E → ... → ... → M
    │                 ↑              │
    │←── a 步 ──→│   └──── b 步 ────┘
                     环入口
```

| 符号 | 含义 |
|:---:|------|
| `a` | 从起点到环入口的距离（节点数） |
| `b` | 环的长度（节点数） |
| `s` | slow 走的步数 |
| `2s` | fast 走的步数 |
| `M` | 第一次相遇点 |
| `x` | 环入口到相遇点的距离 |

---

## 二、第一次相遇

slow 走 `s` 步到达 M：

```
s = a + x + m·b       (绕了 m 圈环)
```

fast 走 `2s` 步到达 M：

```
2s = a + x + n·b      (绕了 n 圈环)
```

两式相减：

```
2s - s = (n - m)·b
s = (n - m)·b
```

令 `k = n - m`，则 **`s` 是环长 `b` 的整数倍**：

```
s = k·b          ... ①
a + x + m·b = k·b
a + x = (k - m)·b = t·b          ... ② (关键)
```

---

## 三、关键同余式

由 ② 得：

```
a + x ≡ 0 (mod b)
a ≡ -x (mod b)
a ≡ b - x (mod b)
```

**含义**：从环入口走 `a` 步，等价于反向走 `x` 步（模 `b` 下同余）。

更直观地说：

```
从环入口出发走 a 步 ≡ 从相遇点出发走 b - x 步（都到达环入口）
```

但 `b - x` 步不是我们想要的。换个角度：

```
从相遇点出发走 a 步:
  当前位置 = (x + a) mod b
           = (x + (b - x)) mod b    (由 a ≡ b - x)
           = b mod b
           = 0
           = 环入口！
```

---

## 四、算法的第二阶段

```
重置 finder 到起点，slow 留在相遇点。
两者每次都走 1 步。

经过 a 步后:
  finder 位置: 0 → 经过 a 步 → 环入口 ✓
  slow 位置:   M → 经过 a 步
              = (x + a) mod b
              = 0 (环入口) ✓

两者在环入口相遇！
```

## 五、数值验证

```
nums = [1, 3, 4, 2, 2]          ← 287 题的链表化视角

链表: 0 → 1 → 3 → 2 → 4
              ↑         ↓
              └─────────┘

a = 3  (0→1→3→2, 环入口 = 2)
b = 2  (2→4→2)
```

**阶段 1：找相遇点**

```
slow: 0→1→3→2→4→2→4   (s=6, M=4)
fast: 0→3→4→4→4→4→4   (2s=12, 也在 4)

s=6, b=2 → s = 3·b ✓
x = 1  (环入口 2 到相遇点 4)
a+x = 3+1 = 4 = 2·b ✓
```

**阶段 2：同步走 a=3 步**

```
finder: 0 → 1 → 3 → 2  (3 步)
slow:   4 → 2 → 4 → 2  (3 步)

相遇于 2 = 重复数 ✓
```

slow 从 M=4 走 a=3 步：在环长 b=2 的圈里，走 3 ≡ 3-2=1 步 → 从 4 走到 2。即 `(x+a) mod b = (1+3) mod 2 = 0` → 环入口。

## 六、直观理解（非数学）

```
假设环入口在位置 E，起点到 E = a 步，环长 = b。
相遇时 slow 走了 s 步，s 是 b 的整数倍。

如果我们把相遇点 M 往回"倒带"a 步，位置是 M - a。
因为 s = k·b 且 s = a + x，有 a = k·b - x。
M 的位置 = 相遇点 = E + x。
M 往回退 a 步 = (E + x) - (k·b - x) = E + (2x) mod b

（等号不直观，跳过。记住结论即可）
```

**一句话总结**：slow 在环内多走的步数恰好能被 a 步"对齐"回入口，因为 s 是环长的整数倍。

## 七、为什么 fast 两步、slow 一步？

如果 fast 和 slow 速度差为 1，fast 每轮相对 slow 多走 1 步。环长 b，fast 一定在 b 轮内追上 slow。如果速度差 >1，可能"跳过头"永远不相遇。

环是指: nums[i] 作为"从 i 指向 nums[i] 的边"。重复数意味着有两个 i,j (i≠j) 使得 nums[i] = nums[j] = dup。所以 dup 这个索引的入度 ≥ 2，就是环入口。

所以 2 是环入口。
