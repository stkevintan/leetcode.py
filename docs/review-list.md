## 799. 香槟塔 回顾要点

### 思路

倒 `poured` 杯酒，每层模拟流量。杯子最多存 1，溢出量 `(v - 1)` 均分给下一层的左右两个杯子：

```
        [poured]
       /        \
  (v-1)/2    (v-1)/2     ← 溢出均分
    [ ]        [ ]
```

逐行递推，只算到 `query_row` 就停（更下面的行不影响结果）：

```python
row = [poured * 1.0]
for i in range(1, query_row + 1):
    next_row = [0.0] * (i + 1)
    for j, v in enumerate(row):
        if v > 1:
            next_row[j] += (v - 1) / 2
            next_row[j + 1] += (v - 1) / 2
    row = next_row
return min(1.0, row[query_glass])
```

### 要点与坑

1. **为什么不用算整个塔**：第 `r` 行只依赖第 `r-1` 行，`query_row` 以下的行对答案无影响；
2. **滚动数组**：只用 `row` 和 `next_row` 两行，空间 $O(\text{query\_row})$；
3. **返回值取 `min(1.0, ...)`**：杯子最多装 1，查询的杯子可能溢出；
4. **上界剪枝**：`poured ≥ 1 + 2 + 3 + ...` 超过某行总容量时，该行以下全满——但逐行模拟本身 $O(\text{row}^2)$ 已经足够；
5. **本质**：不是 DP 状态转移，而是**物理模拟**；`v > 1` 才溢出，溢出的部分是"流量"，不是杯子的存量。

## 316. 去除重复字母 回顾要点

### 思路

删除重复字符，使每个字符**恰好出现一次**且**字典序最小**（等价题 1081）。

单调栈维护答案前缀，遍历时依赖两个状态：

- `cnt[c]`：`c` 在当前位置**之后**还剩多少个（决定能不能弹栈）；
- `instack`：`c` 是否已在栈中（保证每个字符只留一次）。

```python
cnt = Counter(s)
instack = set()
stack = deque()
for c in s:
    if c in instack:
        cnt[c] -= 1
        continue
    while stack and stack[-1] > c and cnt[stack[-1]] > 0:
        p = stack.pop()
        instack.remove(p)
    stack.append(c)
    instack.add(c)
    cnt[c] -= 1
return "".join(stack)
```

### 要点与坑

1. **弹栈条件缺一不可**：`栈顶 > c`（换掉它字典序更小）**且** `cnt[栈顶] > 0`（它后面还会再出现，弹出后能补回来）；后者为 0 时只能保留，即使它很大；
2. **`if c in instack` 也要 `cnt[c] -= 1`**：`cnt` 统计的是"从当前扫描位置往后的剩余次数"，与入不入栈无关，重复出现的字符只留第一次；
3. **栈自底向上就是答案**：每个字符恰好一次、相对顺序已是最小字典序；
4. **对比 402. 移掉 K 位数字**：402 限制"最多删 k 个"（无去重要求），316 限制"每个字符恰好一次"（无删除个数限制）——约束不同，判断条件不同；
5. 复杂度 $O(n)$，每个字符入栈出栈各一次。

## 678. 有效的括号字符串 回顾要点

### 思路

把 `*` 看成三种可能（左括号 / 右括号 / 空串），维护**净左括号数的取值区间** `[minv, maxv]`：

- `(`：区间整体 +1；
- `)`：区间整体 -1，`minv` 与 0 取 max；若 `maxv < 0`，即使把所有 `*` 当左括号也补不回来 → 直接 False；
- `*`：区间发散——`minv - 1`（当右括号用）、`maxv + 1`（当左括号用），`minv` 仍与 0 取 max。

最后 `minv == 0` 说明存在一条路径使净值为 0。

```python
minv = maxv = 0
for c in s:
    if c == '(':
        minv += 1
        maxv += 1
    elif c == ')':
        minv = max(minv - 1, 0)
        maxv -= 1
        if maxv < 0:
            return False
    else:
        minv = max(minv - 1, 0)
        maxv += 1
return minv == 0
```

### 要点与坑

1. **`minv` 与 0 取 max 是剪枝**：负净值代表"前缀中右括号多于左括号"的路径已不可能闭合，丢弃即可，不影响可行性判断；
2. **`maxv < 0` 的检查在 `)` 分支**：`maxv` 是"把 `*` 全当左括号"的最乐观上界，连上界都为负说明任何路径都无法闭合；`*` 分支不会使 `maxv` 变小，所以只需在这里检查；
3. **最后返回 `minv == 0` 而不是 `minv <= 0`**：`minv` 已被截断为非负，若 `minv > 0` 表示所有路径都多出左括号，无解；
4. **对比两种其他解法**：DP（`dp[i][j]` 前 i 个字符能否凑出 j 个净值，$O(n^2)$）、双栈（左括号栈 + 星号栈，星号当右括号救急，$O(n)$ 但需两遍遍历）——贪心区间法 $O(n)$ 时间 $O(1)$ 空间最优；
5. **本质**：不是枚举 `*` 的三种取值，而是对所有路径做**区间收缩/发散**，只保留可达区间。

## 741. 摘樱桃 回顾要点

### 思路

去 (0,0)→(n-1,n-1) 再回，等价于**两个人同时从 (0,0) 出发**，每步各走右/下，樱桃每格只摘一次。两人同步走 t 步后必在同一条反对角线上（每步 r+c 恰 +1），所以：

- 状态 `dp[r1][r2]`（第 t 层），`c1 = t - r1`、`c2 = t - r2`；
- 转移 = 4 种走法组合取 max（两人各自「上一步是上/左」）；
- 同格（r1 == r2）樱桃只计一次。

```python
dp = [[[NEG] * n for _ in range(n)] for _ in range(2)]
dp[0][0][0] = grid[0][0]
for t in range(1, 2 * n - 1):
    cur, prev = t % 2, (t - 1) % 2
    for r1 in range(n):          # 重置当前槽，跳过格不能残留 t-2 层值
        for r2 in range(n):
            dp[cur][r1][r2] = NEG
    for r1 in range(n):
        for r2 in range(n):
            c1, c2 = t - r1, t - r2
            if not (0 <= c1 < n and 0 <= c2 < n):
                continue
            if grid[r1][c1] == -1 or grid[r2][c2] == -1:
                continue
            best = max(dp[prev][pr1][pr2]
                       for pr1 in (r1 - 1, r1)
                       for pr2 in (r2 - 1, r2)
                       if 0 <= pr1 < n and 0 <= pr2 < n)
            if best != NEG:
                gain = grid[r1][c1] + (grid[r2][c2] if r1 != r2 else 0)
                dp[cur][r1][r2] = best + gain
return max(dp[(2 * n - 2) % 2][n - 1][n - 1], 0)
```

### 要点与坑

1. **为什么不能两次贪心/BFS**：两趟共享樱桃计数，第一趟多吃会「吃掉」第二趟的收益，必须联合优化。官方样例 `[[0,1,-1],[1,0,-1],[1,1,1]]` 两次贪心恰好能过（第二趟可绕道补摘），但 3×3 反例 `[[0,1,0],[0,1,1],[1,1,1]]`：贪心 5 vs 最优 6——两条同样 4 颗的路径吃掉的格子不同，第一趟无法判断哪条留给第二趟的剩余价值更大；
2. **BFS 只记「是否到达 (n-1,n-1)」不够**：要的是最大值，visited 去重会把后到的更优路径丢掉；「逐层 BFS + 状态存 max」就是本 DP；
3. **`c1 + r1 = t` 的降维**：每步 r+c 恰 +1，两人同步走必同对角线，四维状态压成 `(t, r1, r2)` 三维；同步不是限制——两条路径步数相同，按共同步数配对前缀即可覆盖所有路径对；
4. **层隔离（ndp / dp[2] 双缓冲）**：转移来源 `(r1-1, r1) × (r2-1, r2)` 必须取自第 t-1 层；升序原地更新会读到本层新值（一步走两步）；
5. **倒序原地也不可行**：被跳过的格子（荆棘/列越界）会残留更早层的值。倒序只解决「读未覆盖」，不解决「跳过格应重置为 NEG」——背包类 DP 每格必更新才能用倒序原地，这题不行；
6. **同格只计一次**：`r1 == r2 ⟺ c1 == c2`（同层同对角线），gain 里第二次格子只在 `r1 != r2` 时加；
7. **终点取 `max(..., 0)`**：完全不可达（-1 堵死）时 dp 为 NEG，返回 0；
8. 复杂度 $O(n^3)$ 时间、$O(n^2)$ 空间（双缓冲）。
